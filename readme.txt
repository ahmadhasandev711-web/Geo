تسعير جغرافي ذكي بناءً على بلد الزائر مع دعم أسعار الصرف الحية وإدارة مخزون المناطق وعمولات الشركاء والبراندات.

== Description ==

بلاجين متكامل لتخصيص متجرك الإلكتروني في ووكومرس حسب بلد الزائر. يتيح لك وضع أسعار مختلفة لكل منطقة جغرافية، تحويل العملات تلقائياً بأسعار صرف حية، التحكم في ظهور المنتجات وعرضها في كل بلد، وإدارة مخزون خاص للمنتجات بكل منطقة جغرافية، بالإضافة إلى نظام متطور لإدارة العمولات والشركاء (البراندات والمسوقين).

=== أهم المميزات: ===
* **تسعير جغرافي مرن:** إمكانية تخصيص السعر لكل منطقة جغرافية (سعر ثابت لكل عملة أو ضرب السعر الأساسي بمضاعف سعر الصرف).
* **دعم أسعار الصرف الحية:** تحديث تلقائي يومي لأسعار الصرف عبر API موثوق ومجاني.
* **إدارة مخزون المناطق:** إمكانية تحديد كمية مخزون مستقلة لكل منطقة جغرافية (سواء للمنتج الأب أو المتغيرات) لمنع البيع لبلاد معينة عند نفاد مخزونها هناك.
* **العرض الجغرافي الذكي:** إخفاء منتجات معينة في بلدان محددة بشكل صديق للـ SEO (عرض صفحة للمنتج بدون زر شراء مع رسالة مخصصة).
* **نظام العمولات والشركاء (Affiliates & Brands):** رتب خاصة لمدراء البراندات والمسوقين، وتتبع روابط الإحالة عبر الكوكيز الآمنة، ولوحة تحكم أمامية متكاملة لكل شريك لمتابعة أرباحه وروابطه التسويقية.
* **حماية من تلاعب الـ VPN:** إعادة فحص البلد ومطابقته لبلد الفاتورة الحقيقي أثناء الدفع لضمان عدم تلاعب الزوار بالبلدان للحصول على أسعار أقل.

== Installation ==

1. ارفع مجلد البلاجين إلى مسار `/wp-content/plugins/` أو قم بتثبيته مباشرة من لوحة تحكم ووردبريس.
2. قم بتفعيل البلاجين.
3. توجه إلى **Masa Geo-Pricing 🡒 الإعدادات** لتهيئة المناطق الجغرافية والعملات ومضاعفات الأسعار.
4. (اختياري وموصى به) قم بتفعيل MaxMind Geolocation من إعدادات ووكومرس العامة للحصول على أفضل دقة في تتبع المواقع.

== Frequently Asked Questions ==

= هل البلاجن متوافق مع HPOS؟ =
نعم، البلاجن متوافق بشكل كامل مع ميزة High-Performance Order Storage في ووكومرس.

= هل أحتاج إلى مفتاح API لأسعار الصرف؟ =
لا، البلاجن يستخدم مزود مجاني لأسعار الصرف بشكل افتراضي، ويمكنك استخدام مفتاح API إذا رغبت.
